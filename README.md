# 나들이 플래너

아이와 함께 갈만한 나들이 행사를 **두 개의 달력**으로 보여주는 정적 웹페이지입니다.

- 🎈 **왼쪽 달력 – 나들이 행사 일정**: 행사가 열리는 날(기간 행사는 매일)에 표시
- ⏰ **오른쪽 달력 – 예약·신청 마감**: 신청 오픈일(점선)과 마감일(색 채움)을 표시하고, 목록에 D-day 표시

달력 위에는 **다음 주말 추천 5개**가 나옵니다. 추천(⭐) 행사를 먼저 놓고, 나머지는 분야가 겹치지 않게 골라 채웁니다.
날짜 칸을 누르면 그날의 모든 일정이 큰 카드로 펼쳐집니다(장기·상시 행사 포함).
행사 상세 창 아래에는 네이버 블로그 등의 관련 글(후기·공지·소개)이 최대 3개 나오고, 네이버 검색 바로가기도 있습니다.

같은 행사는 양쪽 달력에서 연결되어, 한쪽에 마우스를 올리면 다른 쪽도 강조됩니다.
항목을 누르면 장소·대상·비용·신청 방법 등 상세 정보가 열립니다.

## 주소 형식

```
index.html#/{지역}/events/{YYYY-MM}
예) index.html#/sudogwon/events/2026-11
```

지역: `sudogwon`(수도권 전체), `seoul`, `gyeonggi`, `incheon`, `seongnam`(성남·분당 인근)

## 실행

빌드 과정 없이 `index.html`을 브라우저로 열면 됩니다. GitHub Pages 같은 정적 호스팅에 그대로 올릴 수 있습니다.

## 데이터

- `data/config.js`: 분류(공연, 전시, 축제, 체험·교육, 어린이·가족, 지역 행사, 과학·AI·로봇)와 지역 필터
- `data/events.js`: 행사 목록. 필드 설명은 파일 상단 주석 참고
- `node scripts/validate.js`: 데이터 형식 검사

## 매주 자동 업데이트

매주 일요일 아침 예약 작업이 수도권(서울·경기·인천) 가족 행사를 조사해 `data/events.js`를 갱신하고 `main`에 커밋합니다.

- 다음 주말(토·일)에 실제로 열리는 행사 7~10개, 그중 추천 1~2곳은 `pick: true`
- 앞으로 약 4주 안에 열리고 사전 예약·신청이 필요한 행사(이미 마감된 것은 제외)
- 분야 균형: 과학·AI·로봇·코딩·드론 행사는 성남·분당 인근(성남, 용인, 수원, 과천, 서울 강남·송파 등)만, 주마다 많아야 2~3개
- 행사마다 관련 글(네이버 블로그 후기·공지 등) 최대 3개를 `links`에 채움. 본문에 행사 이름이 실제로 나오는 글만 사용
- 지난 행사 중 끝난 지 60일이 넘은 것은 정리

### 관련 글(`links`) 채우는 규칙 — 주간 루틴용

새로 넣는 행사와, `links`가 비어 있거나 3개 미만인 기존 행사(아직 끝나지 않은 것)에 관련 글을 최대 3개 넣습니다.

1. **찾기:** `https://search.naver.com/search.naver?ssc=tab.blog.all&query=<행사 핵심 이름>`을 모바일 User-Agent로 받아 `blog.naver.com/<아이디>/<글번호>` 주소를 모읍니다.
2. **확인:** 각 글을 `https://m.blog.naver.com/<아이디>/<글번호>`로 직접 열어 `og:title`(제목)과 작성일(`YYYY. M. D. HH:MM`, "N시간 전"이면 오늘)을 읽습니다. 본문에 그 행사 이름이 실제로 나오는 글만 씁니다. 이름만 비슷한 다른 단체·다른 지역 행사는 넣지 않습니다. 같은 작품의 다른 지역·작년 공연 후기는 넣어도 됩니다.
3. **고르는 순서:** 아이와 다녀온 후기(`review`) → 주최 측 공지(`notice`) → 일정·예매 정리(`info`) → 기사(`news`). 후기가 있으면 적어도 1개는 후기로 채우고, 같은 블로그 글을 여러 개 넣지 않습니다.
4. **형식:** `{ title: 글 제목 그대로, url: "https://blog.naver.com/<아이디>/<글번호>", source: "네이버 블로그", kind, date: "YYYY-MM-DD" }`. 공식 안내 `url`과 같은 주소는 넣지 않습니다.
5. 맞는 글을 못 찾으면 비워 둡니다. 지어내지 않습니다(화면에 네이버 검색 바로가기가 따로 있습니다).
6. 결과 보고에 "관련 글을 채운 행사 수 / 못 찾은 행사"를 적습니다.
