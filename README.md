# 나들이 플래너

아이와 함께 갈만한 나들이 행사를 **두 개의 달력**으로 보여주는 정적 웹페이지입니다.

- 🎈 **왼쪽 달력 – 나들이 행사 일정**: 행사가 열리는 날(기간 행사는 매일)에 표시
- ⏰ **오른쪽 달력 – 예약·신청 마감**: 신청 오픈일(점선)과 마감일(색 채움)을 표시하고, 목록에 D-day 표시

같은 행사는 양쪽 달력에서 연결되어, 한쪽에 마우스를 올리면 다른 쪽도 강조됩니다.
항목을 누르면 장소·대상·비용·신청 방법 등 상세 정보가 열립니다.

## 주소 형식

```
index.html#/{지역}/events/{YYYY-MM}
예) index.html#/seongnam/events/2026-11
```

## 실행

빌드 과정 없이 `index.html`을 브라우저로 열면 됩니다. GitHub Pages 같은 정적 호스팅에 그대로 올릴 수 있습니다.

## 행사 추가·수정

`data/events.js`의 `regions.{지역}.events` 배열에 항목을 추가합니다. 필드 설명은 파일 상단 주석을 참고하세요.
새 지역은 `regions`에 키를 추가하면 상단 지역 선택에 자동으로 나타납니다.

> 현재 들어있는 데이터는 화면 확인용 **예시**입니다. 실제 행사 정보로 바꿔 사용하세요.
