# 나들이 플래너

아이와 함께 갈만한 나들이 행사를 **두 개의 달력**으로 보여주는 정적 웹페이지입니다.

- 🎈 **왼쪽 달력 – 나들이 행사 일정**: 행사가 열리는 날(기간 행사는 매일)에 표시
- ⏰ **오른쪽 달력 – 예약·신청 마감**: 신청 오픈일(점선)과 마감일(색 채움)을 표시하고, 목록에 D-day 표시

같은 행사는 양쪽 달력에서 연결되어, 한쪽에 마우스를 올리면 다른 쪽도 강조됩니다.
항목을 누르면 장소·대상·비용·신청 방법 등 상세 정보가 열립니다.

## 주소 형식

```
index.html#/{지역}/events/{YYYY-MM}
예) index.html#/sudogwon/events/2026-11
```

지역: `sudogwon`(수도권 전체), `seoul`, `gyeonggi`, `incheon`, `seongnam`(성남·분당 인근)

## 실행

빌드 과정 없이 `index.html`을 브라우저로 열면 됩니다. GitHub Pages 같은 정적 호스팅에 그대로 올릴 수 있습니다.

## 데이터

- `data/config.js`: 분류(공연, 전시, 축제, 체험·교육, 어린이·가족, 지역 행사, 과학·AI·로봇)와 지역 필터
- `data/events.js`: 행사 목록. 필드 설명은 파일 상단 주석 참고
- `node scripts/validate.js`: 데이터 형식 검사

## 매주 자동 업데이트

매주 일요일 아침 예약 작업이 수도권(서울·경기·인천) 가족 행사를 조사해 `data/events.js`를 갱신하고 `main`에 커밋합니다.

- 다음 주말(토·일)에 실제로 열리는 행사 7~10개, 그중 추천 1~2곳은 `pick: true`
- 앞으로 약 4주 안에 열리고 사전 예약·신청이 필요한 행사(이미 마감된 것은 제외)
- 분야 균형: 과학·AI·로봇·코딩·드론 행사는 성남·분당 인근(성남, 용인, 수원, 과천, 서울 강남·송파 등)만, 주마다 많아야 2~3개
- 지난 행사 중 끝난 지 60일이 넘은 것은 정리
